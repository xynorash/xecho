# XEcho: A [Rust](https://rust-lang.org/) rewrite of The [Echo](https://www.gnu.org/software/grub/manual/grub/html_node/echo.html) command from GNU.

Hey, there! Xynorash here!
<br><br>
This project is basically one which aims to reproduce how the [Echo](https://www.gnu.org/software/grub/manual/grub/html_node/echo.html) command on GNU/Linux behaves, as part of my personal arsenal and training materials.
<br><br>
I hope you'll enjoy my version! If there's anything you want to tell me (come on, don't be shy), just send me an email [here](mailto:nashtefison@gmail.com) or open an issue and I'll take care of you.
